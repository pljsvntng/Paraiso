## Interaction and responsive behavior

- The official iframe remains live and lazy-loaded. It shows the resort name and pin, standard camera/zoom/pan controls, satellite view, and Google's attribution.
- **Explore map** enables pointer interaction and keyboard focus within the map. **Finish exploring** returns it to preview mode. Preview mode leaves wheel/touch scrolling with the page. No scroll interception or artificial scrolling delay was introduced.
- The toggle is keyboard accessible, reports its pressed state, and describes the current mode. The iframe has a descriptive title, explicit dimensions, strict-origin referrer policy, and fullscreen support.
- The map uses a full-width landscape frame on desktop, with a readable minimum height on smaller screens. Explicit width constraints prevent an aspect-ratio/min-height combination from creating horizontal overflow.
- The address, configured contact channels, **Get Directions**, **Open in Google Maps**, and existing resort inquiry link remain below the map. External links open in a new tab with `noopener noreferrer`.
- No verified phone number or email existed in the project, and Google Maps also did not publish a phone number on the inspected listing. These remain unset. The existing official Facebook destination is shown; future verified phone/email values render automatically when configured.
- The existing shared reveal observer is reused without modification. Only the location title and map use targeted 800ms fades. Existing 900ms motion elsewhere and reduced-motion accessibility remain intact.
- Google's third-party map connection is disclosed in the existing Contact privacy notice, with a link to [Google's privacy policy](https://policies.google.com/privacy). The site still has no backend, inquiry form, account, or payment processing.
